# Atelier MTG, l'appli

L'appli de l'[Atelier MTG](https://github.com/PierreRibeaucourt/atelier-mtg), sur téléphone et sur ordinateur, sans rien installer : https://app.atelier-mtg.com/

Ce dépôt ne contient que la recette (`.github/workflows/appli.yml`) : l'appli est fabriquée à partir du dépôt de l'Atelier (`outils/atelier/telephone_site.py`) et publiée sur GitHub Pages, à chaque envoi ici et toutes les trois heures.

Son ancienne adresse, https://atelier-mtg.github.io/ (dépôt `atelier-mtg.github.io`), n'est plus qu'une passerelle : elle emporte les decks gardés par le navigateur vers la nouvelle adresse.
